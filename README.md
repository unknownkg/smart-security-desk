# Smart Security Desk

Учебный проект по дисциплине **«Технология разработки программного продукта» (ТРПП)**.

**Назначение:** веб-система учёта камер видеонаблюдения, событий IoT-датчиков и инцидентов службы безопасности.

**Группа:** КС-3-24.  
**Учебный год:** 2026–2027.

## Технологии

- Node.js и Express — REST API.
- HTML, CSS и JavaScript — интерфейс оператора.
- JSON — хранение учебных данных.
- GitHub Issues, ветки и Pull Requests — управление разработкой.
- Postman — проверка API.

## Статус

Проект находится в разработке. Финальный релиз `v1.0.0` выпускается после проверки интерфейса, API и выполнения требований лабораторной работы.

> Распределение обязанностей и подтверждение выполненных задач команды будут добавлены после согласования.
