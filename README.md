# Smart Security Desk — GitHub Pages

Публичная **демоверсия интерфейса**. Камеры, события и инциденты хранятся в localStorage посетителя через браузерный адаптер. Сервер Express и общая JSON-база здесь **не работают**. Демонстрационные данные можно сбросить. Видео не транслируется.

Основной работающий проект Node.js + Express — в ветке [main](https://github.com/unknownkg/smart-security-desk). Релиз [v1.0.0](https://github.com/unknownkg/smart-security-desk/releases/tag/v1.0.0).
