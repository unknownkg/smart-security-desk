# Product Brief: Smart Security Desk

## Заказчик и пользователи

Заказчик — служба безопасности и IT-отдел колледжа или офиса. Основные пользователи — оператор и инженер, обслуживающий камеры.

## Проблема

Камера может перейти в состояние offline, ночью может появиться движение, а дверь — открыться вне расписания. Оператору нужно видеть такие события и фиксировать их обработку в одном месте.

## Решение

Smart Security Desk — веб-система для просмотра состояния камер и событий IoT, регистрации инцидентов и контроля их обработки.

## Границы MVP

- Список камер с состоянием online/offline, расположением и ссылкой на preview.
- События IoT, в том числе motion, door_open, smoke и camera_offline, с возможностью их симуляции через API.
- Регистрация инцидентов с приоритетом, ответственным и статусом.
- Фильтрация инцидентов и REST API.
- Dashboard оператора и сохранение данных в локальном JSON-файле.
- Ссылка на HLS preview при наличии доступного потока.

## Вне MVP

- Распознавание лиц.
- Архив NVR.
- Production-аутентификация.

## Критерии готовности

Приложение запускается через npm start; API отвечает; оператор может просматривать камеры и события, создавать инциденты, менять их статус и фильтровать список. Проект содержит тесты API, README и артефакты GitHub workflow, предусмотренные методичкой.
