# Краткое описание продукта: Smart Security Desk

## Заказчик и пользователи

Заказчик — служба безопасности и IT-отдел колледжа или офиса. Основные пользователи — оператор и инженер, обслуживающий камеры.

## Проблема

Камера может стать недоступной, ночью может появиться движение, а дверь — открыться вне расписания. Оператору нужно видеть такие события и фиксировать их обработку в одном месте.

## Решение

Smart Security Desk — веб-система для просмотра состояния камер и событий IoT, регистрации инцидентов и контроля их обработки.

## Границы минимально жизнеспособного продукта (MVP)

- Список камер с состоянием, расположением и ссылкой на предварительный просмотр.
- События IoT, в том числе `motion`, `door_open`, `smoke` и `camera_offline`, с возможностью их имитации через API.
- Регистрация инцидентов с приоритетом, ответственным и статусом.
- Фильтрация инцидентов и REST API.
- Панель оператора и сохранение данных в локальном JSON-файле.
- Ссылка на HLS-поток при его наличии.

## Вне MVP

- Распознавание лиц.
- Архив NVR.
- Аутентификация для промышленной эксплуатации.

## Критерии готовности

Приложение запускается через `npm start`; API отвечает; оператор может просматривать камеры и события, создавать инциденты, менять их статус и фильтровать список. Проект содержит тесты API, README и артефакты GitHub, предусмотренные методичкой.
