# Smart Security Desk v1.0.0

Первый учебный выпуск **Smart Security Desk** — веб-приложения для учёта камер видеонаблюдения, событий IoT-датчиков и инцидентов безопасности.

## Что вошло в выпуск

- Операторская панель Operations Console: состояние камер, показатели, журнал IoT-событий и очередь инцидентов.
- Работа с инцидентами: создание, назначение ответственного, изменение статуса, фильтры по статусу и важности.
- Разделение состояния камеры и доступности видеопредпросмотра, обработка ошибок потока.
- Уведомления о результатах операций, адаптивный интерфейс и русскоязычные тексты.
- REST API на Node.js и Express с хранением учебных данных в JSON.
- Страница [«Задание с багом»](https://github.com/unknownkg/smart-security-desk/blob/main/public/bug.html) и подтверждённый учебный сценарий [Issue #12](https://github.com/unknownkg/smart-security-desk/issues/12) → [PR #13](https://github.com/unknownkg/smart-security-desk/pull/13).
- README с инструкциями, описанием API, тестирования и распределением обязанностей команды.

## Проверка качества

- Автоматические тесты выполняются через `npm test` (в предыдущей локальной проверке: 16 из 16 успешно).
- Коллекция TC-01–TC-08 проверена в Newman: **9 HTTP-запросов, 20 проверок, 0 ошибок**. [Сохранённый отчёт](https://github.com/unknownkg/smart-security-desk/blob/main/docs/evidence/newman-report.json).
- Графический Postman Desktop/Web **не пройден**: вход на `auth.postman.com` блокировался проверкой Cloudflare. Newman не выдаётся за Postman Desktop. Это известное отклонение от буквального требования методички.
- Для выпуска предусмотрена дополнительная автоматическая проверка на GitHub Actions перед созданием тега.

## Ограничения

Система является **учебным MVP**, а не действующим промышленным центром охраны. Авторизация, полноценный видеорегистратор и СУБД не входят в версию. Камера CAM-01 пока без реальной записи главного входа; её планируется добавить отдельно, с явным обозначением демонстрационного видео. Наличие `online` у камеры не означает, что видеопоток гарантированно доступен.

## Запуск

```bash
npm ci
npm start
```

Откройте `http://localhost:3000`, проверка API: `http://localhost:3000/api/health`. Для тестирования рекомендуется отдельная копия `data/db.json` через переменную окружения `DB_PATH`.
